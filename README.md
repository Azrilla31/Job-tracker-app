# 💼 Job Tracker Web Application

A Flask-based web application to track job applications and manage their status efficiently.  
This project focuses on clean UI design, multi-page functionality, and structured data management.

---

## 🚀 Features

- ➕ Add new job applications with title, company, and date  
- 📊 Track application status (Applied, Interview, Rejected, Offer)  
- ✏️ Edit and update job entries  
- 🗑️ Delete unwanted or outdated applications  
- 📱 Clean and responsive layout  
- 🎨 Simple and modern UI design  
- 🧭 Easy navigation across pages  

---

## 🛠️ Technologies Used

- Python (Flask)  
- HTML5  
- CSS3  
- SQLite  
- Jinja2 templating engine
